## About

I am a software and electronics engineer from **Yemen**. My work connects software architecture, artificial intelligence, embedded systems, automotive electronics, mechatronics, and practical automation.

I enjoy taking a problem from an early idea to a useful, testable system: understand the context, design the architecture, build the smallest reliable version, measure what matters, and improve it through documented iteration.

```text
Understand → Design → Build → Test → Measure → Improve
```

## Selected projects

### [PuzzleVerse-3D](https://github.com/user-hasan/PuzzleVerse-3D)
An extensible 3D puzzle platform combining interactive puzzle experiences, deterministic solving, computer vision, and machine-learning research directions. The repository currently contains the documented project foundation, architecture, CI, and research plan.

`Python` `FastAPI` `Flutter` `OpenCV` `Machine Learning`

### [CityOfAIAgents](https://github.com/user-hasan/CityOfAIAgents)
A file-first orchestration system for modular AI-agent workflows, designed around clear boundaries, reusable skills, and inspectable project state.

`Python` `AI` `Agents` `Automation`

### [ai-skills-catalog](https://github.com/user-hasan/ai-skills-catalog)
A catalog of reusable AI skills for organizing and extending AI-assisted workflows.

`AI` `Skills` `Automation`

### [psmanager-releases](https://github.com/user-hasan/psmanager-releases)
A practical desktop management project for PlayStation environments, focused on local data handling and operational automation.

`Python` `SQLite` `Arduino`
